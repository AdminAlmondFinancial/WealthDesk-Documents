# Product

**Wealth Desk Document Assistant** — a paraplanner attaches a Word/PDF document, picks a house style, and gets back a clean copy with consistent headings, numbering, tables and fonts.

- Users: paraplanners and advisers at Wealth Desk
- Core flow: attach file, choose style (house style, suitability report, annual review pack, client letter, file note), send, review the list of changes, download
- Model: Phi-4 (Microsoft)
- Status: UI only; the C# backend is added later
